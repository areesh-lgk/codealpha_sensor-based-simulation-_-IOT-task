# Sensor-Based LED Control Simulation using Proteus

## Overview
This project is a sensor-based LED control simulation developed using Arduino Uno in Proteus. The system uses an LDR sensor and a temperature sensor to automatically control an LED based on environmental conditions.

## Features
- Automatic LED ON/OFF control
- Uses LDR sensor for light detection
- Uses temperature sensor for temperature monitoring
- Arduino Uno-based simulation
- Designed and simulated in Proteus

## Components Used
- Arduino Uno
- LDR Sensor
- Temperature Sensor
- LED
- Resistor

## Software Used
- Proteus Professional
- Arduino IDE

## Working
The Arduino continuously reads the values from the LDR sensor and the temperature sensor.

- If the LDR value is low OR the temperature value is low, the LED turns ON.
- If the LDR value is high AND the temperature value is high, the LED turns OFF.

This project demonstrates a simple sensor-based automation system using Arduino and Proteus.
